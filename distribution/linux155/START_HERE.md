# Donut + CBrowser + Wayfern — Linux x64

Это переносимый комплект для **Linux x86_64**, не Windows/Wine, не Linux ARM64.
Менеджер: наш порт Donut0.36. CBrowser fork1.33 / technical155.0.8059.39.2;
Wayfern155.0.8059.79. Оба движка включены. Наши native policy модификации
воспроизводимы по точным исходным хешам; это **не пересборка Chromium C++**.

## Быстрый старт

1. Распакуйте в короткий путь, например `~/donut-kit`.
2. Нужны Python3.11+, графическая сессия X11/Wayland и системные зависимости
   GTK3/WebKitGTK4.1/NSS/GBM/ALSA/ayatana-appindicator/libxdo. Менеджер собран
   на Ubuntu24.04; старый glibc несовместим — одного Python недостаточно.
3. Запускайте от обычного пользователя, **не root** и не `nobody`.
   **Ограничение безопасности:** launcher не добавляет sandbox-флаги, но
   унаследованный Linux backend Donut запускает Wayfern с `--no-sandbox` и
   `--disable-setuid-sandbox`. Поэтому включённый Chromium sandbox для Wayfern
   НЕ заявлен. Для недоверенного веб-контента используйте отдельную VM/контейнер
   и непривилегированного пользователя; это не заменяет полноценный sandbox.
   Проверка без этих флагов в WSL завершилась падением renderer и не считается
   PASS. CBrowser и Wayfern проверены только в конфигурации из отчёта.
4. `./Donut-Agent-Kit preflight --json`
5. `./Donut-Agent-Kit verify --json`
6. Прочитайте применимые лицензии и условия Wayfern (https://wayfern.com/tos).
   Для его использования подтвердите явно:
   `./Donut-Agent-Kit accept-wayfern-terms --authorized --json`
   Команда вызывает настоящий движок с официальным флагом принятия условий
   в изолированном HOME комплекта; чужие consent-маркеры не копируются.
7. `./Donut-Agent-Kit launch --json`

Все новые настройки/профили/ключи/логи остаются в `state/`. Личные профили,
куки, токены, vault/DPAPI исходного компьютера в архив **не входят**.
Не копируйте сюда чужой каталог `state`. Для переноса своего рабочего профиля
используйте отдельно согласованный экспорт/импорт и резервную копию.

## Агентам: Codex, Claude Code, Cursor, Cline, Pi и другие

Читайте `AGENTS.md`. Сначала capabilities → status → preflight → verify,
затем явный launch. Включите REST/MCP в настройках менеджера и задайте токен
через локальный UI/секрет-хранилище клиента, не через промпт.

Для REST используйте актуальные маршруты `/v1/profiles`,
`POST /v1/profiles/<uuid>/run` и `POST /v1/profiles/<uuid>/kill`.
CDP-порт возвращается при запуске. Playwright подключается к существующему
профилю через TCP/CDP. Не запускайте вторую копию браузера со своим профилем.
MCP-клиент подключается к loopback `/mcp` с Bearer-токеном; имя конфигурационного
файла зависит от клиента. Не публикуйте токен в командной строке/логе/репозитории.
Все названные клиенты поддерживаются инструкцией, но не все live-тестированы.

Для локальной работы наши policy не требуют подписки поставщика. Это не даёт
доступа к чужим cloud sync/proxy/remote browser/CAPTCHA API и не гарантирует,
что произвольный сайт никогда не покажет антибот. Отдельного сервера лицензий
для нашего offline-local режима нет. Подписи поставщика не подделываются.

## Что upstream, что наше

- Donut — upstream Tauri/Rust + Next.js; лицензия в `licenses/LICENSE`,
  соответствующие исходники в `source/donut036-matching-source.zip`.
  Native-модификации движков воспроизводятся комплектом
  `source/native-linux-reproducer.zip` (проверяемый Python-код, манифесты и
  fingerprint-таблицы; credentials не нужны). Это не исходники Chromium C++.
- CBrowser/Wayfern — нативные Chromium-движки с сохранёнными оригинальными
  ресурсами/уведомлениями внутри своих каталогов. Лицензии третьих сторон,
  включая шрифты, не заменяются нашей product policy.
- Наше: интеграция CBrowser; локальные REST/MCP/explicit page targeting,
  ручные обновления и запрет фонового удаления движков; точная hash-gated
  policy Wayfern, offline bootstrap и локальные fingerprint-таблицы CBrowser;
  изоляция launcher/state, проверка хешей, упаковка и инструкция агентам.
- GeoLite2: данные MaxMind и применимые условия в `licenses/GeoLite2-NOTICE.txt`.
- `146_Cl.txt` — историческое имя файла соответствия версий, не номер движка.

`BUILD.json` фиксирует происхождение. `MANIFEST.json` — хеш каждого файла.
Компиляция, файловая проверка и живой runtime — разные проверки. Builder сам
не заявляет runtime PASS; отдельный отчёт проверки обязателен для релиза.

Откат: закройте только процессы этого комплекта; сохраните изменённый `state`,
используйте предыдущий комплект. Не открывайте профиль более старым Chromium
поверх новых миграций без свежего снимка. Личную установку launcher не заменяет.
